# Contributing

Harvester is currently a design scaffold. Please bring a concrete scenario: target object graph, fields required in your org, expected repeat-run behavior, and the failure you need the tool to explain. Avoid attaching real customer records or credentials.

Read the [SDD](docs/sdd.md) and [ADRs](docs/adr/README.md). Propose significant changes with a new ADR that names the prior decision it supersedes. Keep recipes and test fixtures synthetic. The first implementation should prove the M1 Account–Contact journey before expanding object coverage.

The example JSON is provisional and is not supported by executable code yet.
