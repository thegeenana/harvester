# First Lead dataset

`Harvester Lead Generation v0.1.xlsx` is the human-readable 30-row sample, with field and method notes. `leads-plan.json` is the same dataset mapped to the Apex input shape. It is a PLAN request; it cannot write records without explicitly changing mode and specifying the exact target org ID.

See [first load instructions](../docs/lead-first-load.md). All names and companies are synthetic combinations. Email addresses use example.com. HarvesterKey is a local correlation key.
